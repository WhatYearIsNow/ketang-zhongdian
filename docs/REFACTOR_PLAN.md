## 已发现的问题

工作区与安装版各有独有规则，工作区还缺 YAML frontmatter。规则同时要求教材核验/绝对锚点，又允许无教材/无照片降级；对资料冲突采用多个互斥的“优先来源”。归档、转写提取和链接检查没有可重复执行的实现与测试。

## 本次实施范围

1. 合并两版有效行为，精简 SKILL 入口；细节拆为课程适配、逐字稿、照片、证据、写作与工具参考。
2. 明确三类结果：正常完成、带局限说明完成、阻断。无教材/无绝对锚点不等于未完成；未看图/缺逐字稿/编造来源不能声称完成。
3. 以证据类型处理冲突，未知批注不推归属，枚举补全不伪造课堂原话；照片时刻先验证，录音暂停需分段。
4. 提供三个小型标准库工具：安全转写提取、时间候选计算、本地链接检查。归档移动仍由有上下文的 agent 执行，不自动破坏原件。
5. 合成数据单元/CLI 测试、独立行为评估与代码审查；测试事实边界而非固定标题措辞。
6. 增加 MIT、README、贡献规范、合成 fixtures、CI、变更记录与验证报告，使本目录可独立作为仓库。

## 不纳入本次范围

不重写真实课程笔记，不集成付费 ASR/OCR，不上传私人资料，不代替视觉或专业事实审查。只向获准的私有仓库上传清单中的源码、文档和合成测试。已安装版本的同步须在测试及审查通过后进行，保留本地基线备份。

## 验收标准

入口 frontmatter 可验证，文档引用可达；脚本无第三方运行依赖，坏输入可解释失败且不毁原件；测试覆盖成功、损坏输入、冲突、编码、跨小时/午夜、断链、歧义、目录边界与写入失败。独立 agent 用未给答案的真实形态合成任务生成笔记后检查结果。

跨平台 CI 结论绑定实际执行的提交 SHA 和运行链接；没有访问真实课堂照片的测试不能叫视觉准确性验证。发布包不包含本机路径、私有基线或课堂资料；开源项目文档中的通用目录示例保留。

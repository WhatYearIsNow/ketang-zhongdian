# 照片与时间校准

## 逐图记录

每张记录文件名、完整日期时间及其来源、可见标题/公式/批注、是否本课、清晰度、小节和处理决定。`IMG_YYYYMMDD_HHMMSS.jpg` 通常提供拍摄时刻；EXIF 可能清除，截图/改名可能使文件名时间失真，修改时间不能默认为拍摄时间。

看图识别个人截图、聊天、支付页，即使日期在课内也排除。其他课图片单独说明。连拍可选最清晰图，但每张都有归宿；模糊图排除，不猜内容。不明批注写“批注归属不明”；原生红字不自动等于老师强调。

## 校准模型

仅在录音连续、同一时钟适用时：

`录音起点 = 照片完整日期时间 − 内容对应的录音相对时间`

找多个内容唯一的对应点，例如黑板写到哪一行、老师逐字念某句。一页讲数分钟时只能给匹配时间范围，不把翻页时刻说成已知秒点。脚本仅支持点候选，区间/分段手工建表。

```json
{
  "anchors": [
    {"photo_time": "2026-10-23T09:04:10", "transcript_time": "05:00", "evidence": "黑板公式完成最后一行"},
    {"photo_time": "2026-10-23T09:14:12", "transcript_time": "15:00", "evidence": "老师念出照片上的唯一例题数据"}
  ]
}
```

运行 `python scripts/calibrate.py anchors.json` 得到偏移中位候选及逐点残差。默认 120 秒仅是筛查阈值，可以调整；它和最大残差都不是实际误差上界。不能因返回 candidate 就写“精确校准”。

| 状态 | 可声称的结论 |
| --- | --- |
| 多点候选 | 多个独立内容匹配支持近似起点，写依据与剩余限制 |
| 单点暂定 | 只有一组匹配，无法交叉验证，不能指定无依据误差 |
| 分段 | 暂停/拼接使偏移改变，各段分别匹配 |
| 不可用 | 保留录音相对时间；照片依内容定位，绝对换算未知 |

有照片但定不了绝对锚点仍可完成内容笔记；有照片却没看不能交付。无照片直接采用相对时间。不要强行把不确定定位写成“正好位于 xx:ss”。

## 交叉验证

以“录音起点＋录音时长≈结束时刻”核对，不用上课钟点代替。课间空档只是辅助。跨午夜用完整日期，检查时区、设备时钟与暂停情况。

长课保留工作表：`照片 → 内容 → 录音区间/未知 → 小节 → 采用/排除及理由`。一致偏移下时间单调不能证明内容匹配，只能辅助检查录入。工作表放任务工作区，不把全套分析堆入正文。

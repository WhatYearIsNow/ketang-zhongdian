# 归档与课程包适配

## 独立使用

用户指定的输入与输出目录优先。无课程包时在指定目录组织 `recordings/`、`notes/` 与 `notes/images/日期/`，或者沿用既有命名。不要创建虚构的课程卡、教材或学习档案。本 skill 不要求特定笔记软件、学校、操作系统、CLI 或远程服务。

上课日期缺失但内容可整理时，可先用 `待确认-主题.md` 和独立配图目录交付注明日期待确认的内容笔记，不拿当前日期冒充上课日期。先询问日期再做依赖日期的最终归档，不覆盖既有讲次。课程身份仍歧义且会影响资料选取时，不自行选课套教材；只继续清点与输入保护。

## 课程包模式

有共享引擎与课程卡时先读，事实来源遵守课程卡。默认约定：

| 内容 | 位置 |
| --- | --- |
| 原音频、DOCX/TXT 转写 | `<课程包>/课程录音/` |
| 课堂笔记 | `<课程包>/课堂重点/MM-DD-主题.md` |
| 本讲照片、课件摘页 | `<课程包>/课堂重点/images/MM-DD/` |
| 物理实验类课程卡指定的合并记录 | `<课程包>/实验记录/` 及其 `images/MM-DD/` |
| 教材/真题 | `<课程包>/knowledge/`，仅使用入库版 |

这些默认值不能覆盖课程卡。音频如 `MMDD 课名.m4a` 保留原名；转写稿保留稳定名，不强制改为 `MMDD.docx`。新提取 TXT 优先同一 stem；课程卡要求 `MMDD.txt` 时按卡执行，冲突不得覆盖。

同日多节课、跨年同月日会碰撞，先查已有文件，按本地约定增加年份/主题/节次后缀并同步链接。已有图片引用不主动迁移。新照片可取名 `HHMMSS.jpg`，重名比较哈希，不同图加后缀；大小相同不代表内容相同。

## 归档次序

1. 列出完整文件，排除 `~syncthing~*.tmp`、`.partial`、`.crdownload` 等同步或下载中产物。预期音频尚不存在时写“音频待归档”，用文字时间码，不造假链接。
2. 用文件名、内容与上下文确定课程和日期；空目录不是身份证据。唯一对应可继续，有歧义再问。
3. 易失附件先复制到课程包受控位置并核对哈希。照片未看图前可暂留 `课程录音/`，不能直接全部进入 `images/`。
4. 看图分类后将本课照片归入讲次配图目录。非本课与敏感截图留在受控原目录，不删除、不复制进公开笔记，也不在报告转录敏感数据。
5. 目标存在、内容相同且无引用依赖后才清理重复源件。不同内容不覆盖；改名或移动同步更新受影响链接。

只修改本次相关文件，不自动改 `profile/`、其他课程、Obsidian 设置或 skill 安装目录。开发维护中安装 skill 的授权不等于每次整理课都有权修改安装版本。

## 系列笔记与回访

第二讲起读最近相关一讲的作业/预告/行动项，再核对本次回顾。无上一讲就不编衔接；不改前一讲来制造一致性。只有记录能确认的课次才编号。

缺历史 TXT 时先提取，再核对旧笔记的枚举吞项、数字、时间码和作业，说明实质修订，不因此重写整篇。手工音频链接原样保留，包括链接粒度。

Obsidian 是可选集成：用环境提供的能力读取或预览即可，不硬编码安装路径，不要求运行桌面版才能交付 Markdown。
